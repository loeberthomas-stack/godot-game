# Companions

Roster and tagging. Draft — names, elements and roles are ideas, not final.

## Principles
- **Data, not code.** Companions, spells, tags, items and statuses are data files. Adding companion #11 or #100 = a data file (+ art), never a new system. New spell *behaviours* may need code; new spells built from existing behaviours must not.
- **Roles are tendencies, not boxes** — hybrids allowed (e.g. a tanky healer).
- **Tags:** every companion has a **type** (see `combat.md`; one now, a second later) and an **archetype**: tank, bruiser, assassin, ranged damage, support, controller. Hybrids allowed.
- **Long term:** Pokémon-scale roster (100+) is the horizon. Prototype: 4, then 10.
