# Style Guide

_Concrete style chosen together with the game concept (D9). Must exist before the first asset._

## Process rules (apply now)
- Greybox first: shapes + solid colors until gameplay is fun.
- One source family per game: one creator/pack or one fixed generation recipe — never a mix.
- Prefer procedural / in-engine art (shaders, particles, simple geometry).
- Juice over detail: screen shake, hit flashes, particles, sound feedback.
- All generated art runs through the shared unifying post-process (palette limit / outline shader).
- Only tools/tiers whose terms allow commercial use.
